## What propical changes

- **Rebrand + brand design**: RentTools → propical, with a full brand system (palette, typography, logo, voice) in [docs/ux/index.html](../docs/ux/index.html).
- **Lusophone-first i18n**: UI oriented for Portuguese-speaking users (pt-BR), plus es/en.
- **Message templates**: per-property templates with variables, multi-language.
